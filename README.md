## 如何使用

1. 悬浮球捕获快照 → 快照审查里分享/导出（zip 内就是节点树 JSON）；
2. 把提示词 + 快照 JSON 一次发给 AI（温度调 0）；
3. 拿回的规则 JSON 直接粘进本地订阅即可；
4. 不生效时把失败原因 + 旧规则回喂给 AI 重写（手册里给了"加强模式"的重试话术）。

提醒：光发截图不行——AI 拿不到节点属性就写不出可靠选择器，必须用快照 JSON

### 重要：复杂节点的定位策略
如果目标节点本身没有 id/文本/描述（vid/text/desc 为空），必须使用关系定位：
1. **父子关系**：通过有特征的父节点定位，如 `parent[id="xxx"] > child[index=2]`
2. **兄弟关系**：通过有文本的兄弟节点定位，如 `text="跳过" + sibling(index=1)`
3. **祖先链**：逐层向上找有特征的祖先，组合成完整路径
4. **位置索引**：同类节点中用 index 区分，如 `class="ImageView"[index=3]`
5. **组合条件**：多个弱特征组合，如 `class="TextView"[text.length>0][clickable=true]`

绝对不要因为节点没有直接特征就返回空规则，必须尝试关系定位。


六、注意事项 / 已知坑
提示词里要求 snapshotUrls: "https://i.gkd.li/i/{快照id}"——原版 GKD 里快照分享链接就是这格式，可填可不填，不影响规则执行。
key 字段：导入时如果和已有规则冲突，GKD-Plus 会自动重排；原版手动导入时注意不要和同应用已有规则组 key 重复。
AI 生成的规则必须用真机验证——选择器在"当前快照里唯一"不代表在真实界面永远唯一，actionMaximum / resetMatch / actionCd 这些参数建议照抄模板里的推荐值。
